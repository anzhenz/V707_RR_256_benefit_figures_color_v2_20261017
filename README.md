# ECG：全部256例FP减少案例

下载到本地后双击 `index.html` 筛选浏览全部256例，或直接查看 `images/`。每例沿用177例错误图集的四视图、颜色和尺寸，图内附简要说明；完整字段与核实说明在 `case_descriptions.csv`。

## 优势的组成

| 类别 | 数量 | 占256例比例 |
|---|---:|---:|
| 优势｜RR规则删除底层FP | 23 | 8.98% |
| 优势｜模型删除底层FP | 227 | 88.67% |
| 优势｜FP重新匹配为TP（候选保留） | 6 | 2.34% |

FP净减少 = 250个底层FP候选直接删除 + 6个FP重新匹配为TP = 256。\
模型直接删除227个FP，同时产生6个匹配重分配收益，因此模型阶段FP净减少233；RR再直接删除23个FP。RR这23例中，Rule 1为19例，Rule 2为4例。\
FP重新匹配为TP（候选保留）意思是同一GT附近有重复候选，模型删掉一个、保留另一个，真实心搏仍被检出。以MITDB/105为例：\
| 候选 | 底层评价 | 模型筛选后 |
|---|---|---|
| AP#1703 | 先匹配到GT，记为TP | 删除 |
| AP#1704 | 同一GT已被占用，记为FP | 保留，接替匹配GT，记为TP |

## 匹配与位置分类

| 类别 | 数量 | 占256例比例 |
|---|---:|---:|
| 最近专家标注前超过150ms | 198 | 77.34% |
| 最近专家标注后超过150ms | 47 | 18.36% |
| 容差内重复候选，删除原TP，FP重新匹配为TP | 6 | 2.34% |
| 容差内重复候选，删除重复候选，保留TP | 3 | 1.17% |
| 容差内重复候选，删除所有重复候选，最终漏检 | 2 | 0.78% |

±150ms是评价匹配容差；+100ms是模型相对当前AP最多可观察的未来范围，两者用途不同。

两例同时出现优势和劣势：105/AP1906、203/AP891虽然在底层被标为FP，但均处于真实心搏匹配容差内，它们出现在256例清单中，是因为原FP候选被删除；也出现在80例新增FN中，是因为真实心搏漏检，即FP减少伴随真实心搏漏检。

## 图例

- 红色五角星：当前复核AP，即底层阶段的FP。该点最终可被删除，也可保留为TP。
- 橙色倒三角及点线：全部原始动态阈值AP，包括后来被删除的候选。
- 蓝色上三角及虚线：专家真实心搏参考位置，不要求恰在正向峰顶。
- 浅色区域：波形输入−150～+100ms，实际末采样点+99.5ms。
- 四视图：ECG局部±0.5s、MEAN_TEST局部±0.5s、ECG节律±3s、ECG历史−20～0s。

长视图使用分箱最小/最大值保留极值，局部视图保留全部采样点。20秒背景及窗口外波形仅供离线人工复核，模型实际历史是前30个原始AP窗口。模型删除后的候选未进入RR评估，其空RR字段和history_stable=0不表示实际节律不稳定。

## 文件与复现

- `images/`：全部256张PNG，按三类处理结果和记录分目录。
- `case_descriptions.csv`：逐例处理结果、概率、专家与匹配关系、RR状态、规则、说明和图片路径。
- `benefit_*_counts.csv`：数量与比例；`audit/`保存原始汇总以便追溯。
- `report_examples/`：5例PNG与SVG；`report_captions.md`给出对应说明。
- `index.html`：无需联网的筛选图集，可按阶段、记录和匹配关系筛选。
- `plot_benefit_cases.py`、`plot_error_cases.py`、`export_benefit_wavepack.py`：本轮代码及原有只读绘图依赖。
- `assets/plot_font.ttf`：统一中文字体；`file_registry.json`登记全部交付文件SHA256。

使用numpy、matplotlib、pillow运行 `python -B plot_benefit_cases.py 原始优势波形包.zip 新输出目录`。首次缺字体时需pymupdf；原177例图集如位于输出目录的同级指定目录，会附带复用两张FN图。
